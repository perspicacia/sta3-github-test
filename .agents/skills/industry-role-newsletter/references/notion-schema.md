# Notion 데이터베이스 스키마

데이터베이스 이름 기본값: `산업·직무 뉴스레터 자료함`

## 필드

| 필드 | 형식 | 용도 |
|---|---|---|
| 자료명 | 제목 | 원문 또는 자료의 짧은 제목 |
| 구분 | 선택 | 산업 동향, 직무 동향, 취업 실전 |
| 산업 | 다중 선택 | 이커머스, 콘텐츠·엔터테인먼트 등 |
| 직무 | 다중 선택 | 데이터 분석가, BI Analyst 등 |
| 핵심 요약 | 텍스트 | 확인한 사실을 1~2문장으로 요약 |
| 취업 활용 | 텍스트 | 이력서·포트폴리오·면접 연결점 |
| 이번 주 행동 | 텍스트 | 바로 실행할 행동 1개 |
| 출처 | URL | 원문 링크이자 중복 확인 기준 |
| 출처명 | 텍스트 | 기관·회사·공식 문서 이름 |
| 발행일 | 날짜 | 원문 게시일, 모르면 비워 둠 |
| 수집일 | 날짜 | 조사한 날짜 |
| 신뢰도 | 선택 | 공식 원문, 기업 공식, 보조 자료 |

## 생성용 SQL DDL 예시

```sql
CREATE TABLE (
  "자료명" TITLE,
  "구분" SELECT('산업 동향':blue, '직무 동향':purple, '취업 실전':green),
  "산업" MULTI_SELECT('이커머스':orange, '콘텐츠·엔터테인먼트':pink),
  "직무" MULTI_SELECT('데이터 분석가':blue, 'BI Analyst':green),
  "핵심 요약" RICH_TEXT,
  "취업 활용" RICH_TEXT,
  "이번 주 행동" RICH_TEXT,
  "출처" URL,
  "출처명" RICH_TEXT,
  "발행일" DATE,
  "수집일" DATE,
  "신뢰도" SELECT('공식 원문':green, '기업 공식':blue, '보조 자료':gray)
)
```

기존 데이터베이스의 필드명이 다르면 새 필드를 임의로 추가하지 말고, 의미가 가장 가까운 기존 필드에 맞춘다. 필수 정보가 담기지 않을 때만 사용자에게 변경 여부를 확인한다.
